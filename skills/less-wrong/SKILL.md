# Less Wrong: Close The Loop With Reality

The goal is not to defend the current position. It is to improve the decision
as evidence changes.

## Method

1. State the decision, deadline, and reversible alternatives.
2. List the beliefs that must be true for the preferred choice to win.
3. Assign coarse confidence: low, medium, or high. Use percentages only when
   they improve a real expected-value calculation.
4. Record evidence for and against each belief. Weight direct behavior,
   measured outcomes, and primary sources above opinions or analogies.
5. Define what observation would falsify or materially weaken each belief.
6. Find the cheapest, fastest test that could change the decision. Prefer
   payments, usage, measured performance, or reproducible checks.
7. Update the belief and decision after the test. Preserve the prior view so the
   correction is visible rather than rewritten.

## Output

| Belief | Confidence | Evidence for | Evidence against | Falsifier | Next test |
| --- | --- | --- | --- | --- | --- |

Then state:

- **Decision now:** the least-wrong choice under current evidence.
- **Critical uncertainty:** the belief with the highest decision sensitivity.
- **Update rule:** the exact result that changes the decision.
- **Review point:** date or event for reassessment.

## Boundaries

- Do not manufacture precision from weak evidence.
- Unknown, unmeasured, and false are different states.
- Confidence is not evidence. Effort already spent is not evidence.
- For high-cost irreversible actions, require stronger evidence and a smaller
  reversible precursor.
